# Aqua Guard upgrade - HANDOFF (state at 2026-11-16)

## FLASHING THE GATEWAY - READ FIRST (2026-11-16)
**Flash the gateway ONLY with `node scripts/flash_gateway.mjs COMxx`. Never `arduino-cli upload`, never the Arduino IDE Upload button.**
Why: the gateway partition table (`firmware/gateway/partitions.csv`) makes NVS 0x9000-0xEFFF, but the core's upload recipe also writes `boot_app0.bin` (8 KB) at 0xE000,
which is the LAST NVS page. When that page was the active one, the Wi-Fi ssid/pass and `setup done` vanished (log: "Wrote 8192 bytes at 0x0000e000").
The script writes the application only (0x10000), so Wi-Fi, admin hash, MQTT settings and the node registry survive. Older notes below that say "normal upload, NVS stays" are WRONG.
`.claude/settings.json` denies `arduino-cli upload` on the gateway for Claude sessions. A permanent fix (NVS 0x9000/0x5000 + otadata 0xE000/0x2000) needs a one-time re-setup of the gateway: not done, ask the owner.


Read this first after a restart / `/clear`. The spec is committed as `docs/SPEC.md` (a copy of the original `AQUA_GUARD_UPGRADE_PROMPT.md`, which stays untracked in the working folder).
